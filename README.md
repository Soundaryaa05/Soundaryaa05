## 🤖 Explainable Human Activity Recognition

A research-oriented project exploring **Explainable Artificial Intelligence (XAI)** for Human Activity Recognition (HAR). The goal is to build models that not only recognize activities accurately but also explain *why* a prediction was made.

### Research Focus

- Transformer-based Human Activity Recognition
- Explainability using Grad-CAM and attention visualization
- Wearable sensor data analysis
- Surveying recent HAR research papers
- Building an interpretable deep learning pipeline balancing accuracy and transparency

**Long-term Goal**

Develop an explainable HAR system capable of identifying activities while providing meaningful visual and analytical explanations for every prediction.
